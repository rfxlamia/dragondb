Monospace — JetBrains Mono new in this revision

The SQL editor and the Generated SQL inspector (Roadmap Phase 1) need a mono face. SwiftUI got one free from the system; CSS needs it declared.

SELECT name, email FROM users WHERE name LIKE '%Agus%' ORDER BY created_at DESC LIMIT 20;

Tabular numerals — result grid

Digits must align vertically in the results table. Inter supports font-variant-numeric: tabular-nums; the Windows system font does not do this reliably, which is part of why the font is bundled rather than left to the OS.

Focus ring — the changed rule

outline: 2px solid var(--primary-600); outline-offset: 2px;
The 2px offset gap shows the page background, so the ratio that matters is ring-against-background, not ring-against-button. Computed: primary-600 vs white 4.81:1, vs neutral-100 panel 4.43:1 — both clear the 3:1 UI-component threshold. Using an inset shadow instead would put the ring against the button fill and make it invisible on primary buttons.

Micro-copy — neutral-friendly register

  • CTA: “Connect database” · “Run query” · “Add block” — verb-led, 1–3 words
  • Secondary: “Cancel” · “Not now”
  • Placeholder: “Host (e.g. localhost)” · “Search tables”
  • Validation error: “That host doesn’t look reachable. Check the address and try again.”
  • Failed action: “Couldn’t run this query. Check the blocks, then try again.”
  • Empty state: “No tables yet — connect a database to get started.”
  • Success: “Connected.” / “Query finished.”

Known gap — not covered by this brief

Dark mode. The SwiftUI app inherited some system appearance handling for free; a webview does not. Multi-theme support is an explicit later extension of brand-design and is not defined here. Until it is, the app ships light-only on all three platforms — Windows and Linux users will notice. Flagging it so nobody assumes it is covered.
